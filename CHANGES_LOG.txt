================================================================================

had no matching routes in App.tsx, causing blank pages.

ROOT CAUSE: Sidebar.tsx had links but App.tsx had no <Route> entries. Components
existed as reusable components but needed view wrappers.

"TypeError: Cannot read properties of null (reading 'useContext')" due to
dual React instance issue. Fixed by replacing Radix Tabs with plain
div/button + conditional rendering.
